02 / HISTORY

개발·운용 배경

나발 그룹과 Naviris는 두 나라의 공동 사업으로 2000년에서 2010년 사이 건조된 네 척을 소개한다. 업체가 공개한 공통 길이는 약 153m다. [1]

03 / VARIANTS

형식과 비교

프랑스와 이탈리아의 함명이나 행정상 함종 표기가 달라도 같은 건조 사업에 속한다. 영국 Type 45와 방공 역할은 비슷하지만 별도 함급이다. [1]
